# Эмулятор оболочки ОС — вариант 23

Практическая работа по дисциплине «Конфигурационное управление».

Реализованы два этапа: **REPL** и **Конфигурация**.

## Этап 1

- консольный интерфейс;
- приглашение вида `username@hostname:~$`;
- реальные имя пользователя и имя компьютера;
- обработка аргументов в кавычках;
- команды-заглушки `ls` и `cd`;
- команда `exit`;
- сообщения об ошибках.

## Этап 2

Программа принимает два параметра:

- `--vfs` — путь к физическому расположению VFS;
- `--script` — путь к стартовому скрипту.

При запуске оба параметра выводятся на экран.

Стартовый скрипт выполняется по строкам. На экран выводятся сама
команда и результат её выполнения. После первой ошибки скрипт
останавливается.

На втором этапе VFS ещё не загружается. Программа только принимает
путь к ней. Подключение VFS начинается на третьем этапе.

## Структура

```text
src/        исходный код
tests/      автоматические тесты
startup/    стартовые скрипты
scripts/    bat-файлы для проверки параметров
run.bat     обычный запуск программы
README.md   описание проекта
```

## Запуск

Обычный запуск:

```powershell
.\run.bat
```

С путём к VFS:

```powershell
.\run.bat --vfs "пример\виртуальная_система.xml"
```

Со стартовым скриптом:

```powershell
.\run.bat --script startup\demo.txt
```

С двумя параметрами:

```powershell
.\run.bat --vfs "пример\виртуальная_система.xml" `
--script startup\demo.txt
```

## Проверочные bat-файлы
