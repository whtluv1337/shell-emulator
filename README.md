# Эмулятор оболочки ОС — вариант 23

Практическая работа по дисциплине «Конфигурационное управление».

В этом коммите реализован первый этап: REPL.

## Что реализовано

- консольный интерфейс;
- приглашение вида `username@hostname:~$`;
- реальные имя пользователя и имя компьютера;
- обработка аргументов в кавычках;
- команды-заглушки `ls` и `cd`;
- команда `exit`;
- сообщения об ошибках.

## Запуск

```powershell
.\run.bat
```

## Тесты

```powershell
python -m unittest discover -s tests -v
```

## Пример

```text
lana@computer:~$ ls "Моя папка"
ls: ['Моя папка']
lana@computer:~$ неизвестная
ошибка: неизвестная команда: неизвестная
lana@computer:~$ exit
```
